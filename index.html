Proyek

Sistem Kontrol Akses RFID

Kartu RFID berfungsi sebagai kunci. Arduino membaca ID kartu, dan hanya kartu terdaftar yang mengaktifkan relay, misalnya untuk kunci pintu. Hasilnya tampil di layar LCD dan LED hijau.

Saya merancang rangkaian dan menulis programnya.

Arduino, RFID MFRC522, LCD I2C, relay, C++

Lihat kode di GitHub

Kendali Servo Jarak Jauh dengan ESP32 dan Blynk

Servo digerakkan dari HP. ESP32 terhubung ke Wi-Fi, menerima perintah dari aplikasi Blynk, lalu memutar servo ke 0° atau 180° dari mana saja.

Saya menulis programnya dan merangkai perangkat kerasnya.

ESP32, Blynk, servo, C++
